# Licitações como governança pública

Site em fluxo contínuo para GitHub Pages, com apresentação, ferramentas e infográficos.

## Estrutura

- `index.html`: apresentação principal.
- `checklist/index.html`: check-list de pregão.
- `calculadora/index.html`: calculadora de pesquisa de preços.
- `assets/`: infográficos utilizados na apresentação.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.

Depois disso, a apresentação ficará disponível na URL do GitHub Pages. As ferramentas ficarão em `/checklist/` e `/calculadora/`.
